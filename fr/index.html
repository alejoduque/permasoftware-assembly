PERMASOFTWARE ASSEMBLY

une plateforme de logiciels à faible empreinte pour l'action climatique et la souveraineté technologique

Des artistes-codeurs et des activistes du climat font des logiciels ensemble. Ces logiciels aident les campagnes climatiques. Ils consomment peu d'énergie et ils durent. Le groupe garde le contrôle de ses outils, de ses données et de ses serveurs. Nous appelons cela la souveraineté technologique.

1. principes

La Permasoftware Assembly est une plateforme ouverte. Un logiciel à faible empreinte est simple, durable, sobre en énergie et réparable. Six principes guident chaque projet :

  • Simple. Utiliser peu de pièces et peu de dépendances.
  • Durable. Faire des outils qui fonctionnent pendant des années.
  • Sobre en énergie. Utiliser du vieux matériel et de petits serveurs.
  • Réparable. Publier le code. Écrire des instructions courtes.
  • Local d'abord. Garder les données dans le groupe. Ne pas pister les personnes.
  • IA critique. Utiliser l'IA seulement quand elle aide le groupe. Parfois, le meilleur choix est de ne pas utiliser d'IA.

sources :: permacomputing :: Compost Engineers (Varon & Egaña, Coding Rights, 2024)

2. carte

Les projets se relient en trois branches : écouter, décider et diffuser.

3. projets

Ces projets existent déjà. Ils sont les premières parties de la plateforme.

Radiolibre

Une radio communautaire sur un petit serveur. Icecast envoie l'audio et un lecteur web statique le reçoit. Les auditeurs n'ont pas besoin de compte.

tourne sur :: un VPS, Icecast, nginx :: radiolibre.altred.xyz :: code

iScream

Passer à l'antenne depuis le navigateur d'un téléphone. Pas besoin d'application ni de compte. Le serveur ne garde ni audio ni journaux d'accès. Un pont relie le chat IRC et le groupe Telegram.

tourne sur :: Node, ffmpeg, Ergo IRC :: reporta.altred.xyz :: code pas encore public

LiquidIce

Un bot Telegram pour un groupe. Les membres envoient des photos, des textes, de l'audio et des vidéos. Le bot fait un site d'archives et un flux radio. Il garde une copie sur archive.org.

tourne sur :: Raspberry Pi 3B+, Liquidsoap :: code pas encore public :: première version Telegram2Icecast

KLAP :: Klimat Action Protocol

Un outil libre pour les décisions de groupe. Une personne écrit une affirmation. D'autres personnes ajoutent des raisons : parce que, mais, cependant. L'outil montre où le groupe est d'accord.

tourne sur :: Django, Docker, votre propre serveur :: klap.altred.xyz :: code :: basé sur arguman.org

AudioMoth scripts

Des scripts pour les enregistrements de terrain des enregistreurs AudioMoth. Ils trouvent des événements sonores, calculent des indices acoustiques et font un calendrier saisonnier. Tout le traitement est local, sans cloud.

tourne sur :: un ordinateur portable, Bash, Python, ffmpeg :: bioacustic-scripts :: audiomoth-scripts

SoundWalk :: DerivaSonora

Une application mobile pour les balades sonores. Enregistrer des sons avec leur lieu, ajouter des notes et réécouter sur une carte. Elle fonctionne hors ligne : sans compte, sans serveur, sans pistage.

tourne sur :: téléphones Android, navigateur :: biomapp.vercel.app :: code pas encore public

4. suite

L'étape suivante est un réseau qui n'a pas besoin d'internet ni des grandes entreprises.

  • Reticulum. Une pile réseau pour les réseaux maillés. Elle fonctionne sur radio LoRa, radio par paquets, Wi-Fi et internet. Les groupes envoient des messages sans serveur central.
  • Telegram. Beaucoup de groupes utilisent Telegram aujourd'hui. Les bots restent la porte d'entrée simple. Plus tard, un pont relie Telegram et Reticulum.
  • IA locale. De petits modèles tournent sur le matériel du groupe. Exemples : transcription des archives radio, résumés des débats KLAP. Aucune donnée ne va dans un cloud.
