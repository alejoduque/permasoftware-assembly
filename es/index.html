PERMASOFTWARE ASSEMBLY

una plataforma de software de baja huella para la acción climática y la soberanía tecnológica

Artistas-programadores y activistas del clima hacen software juntos. El software ayuda a las campañas climáticas. Nuestro objetivo: software que usa poca energía y dura mucho tiempo. También queremos soberanía tecnológica: el grupo controla sus herramientas, sus datos y sus servidores.

dónde está el código :: GitHub aloja este sitio y el código. Microsoft es dueño de GitHub. Usamos GitHub porque muchas personas buscan código allí. Es un compromiso, y lo sabemos. Radiolibre, iScream y KLAP funcionan en un pequeño servidor alquilado que administramos nosotros.

1. principios

La Permasoftware Assembly es una plataforma abierta. El software de baja huella es simple, duradero, ligero en energía y reparable. Seis principios guían cada proyecto:

  • Simple. Usa pocas partes y pocas dependencias.
  • Duradero. Haz herramientas que funcionen muchos años.
  • Ligero en energía. Usa hardware viejo y servidores pequeños.
  • Reparable. Publica el código. Escribe instrucciones cortas.
  • Primero local. Guarda los datos en el grupo. No rastrees a las personas.
  • IA crítica. Usa IA solo cuando ayuda al grupo. A veces la mejor opción es no usar IA.

3. siguiente

El siguiente paso es una red que no necesita internet ni grandes empresas.

  • Reticulum. Una pila de red para redes en malla. Funciona sobre radio LoRa, radio por paquetes, Wi-Fi e internet. Los grupos envían mensajes sin un servidor central.
  • Telegram. Muchos grupos usan Telegram hoy. Los bots siguen siendo la puerta de entrada simple. Después, un puente conecta Telegram y Reticulum.
  • IA local. Modelos pequeños funcionan en el hardware propio del grupo. Ejemplos: voz a texto para archivos de radio, resúmenes de debates en KLAP. Ningún dato va a una nube.
