PERMASOFTWARE ASSEMBLY

una plataforma de software de baja huella para la acción climática y la soberanía tecnológica

Artistas-programadores y activistas del clima hacen software juntos. El software ayuda a las campañas climáticas. Usa poca energía y dura. El grupo controla sus herramientas, sus datos y sus servidores. A esto lo llamamos soberanía tecnológica.

1. qué

La Permasoftware Assembly es una residencia de encuentro y una plataforma abierta. El software de baja huella es simple, duradero, ligero en energía y reparable.

De octubre a diciembre de 2026, la Assembly realiza tres encuentros de trabajo. Hay un encuentro en cada región lingüística de Suiza: alemana, francesa e italiana.

En cada encuentro, el grupo hace herramientas en común. El grupo usa KLAP para encontrar posiciones compartidas. Después de los encuentros, publicamos un resumen y el código.

2. principios

  • Simple. Usa pocas partes y pocas dependencias.
  • Duradero. Haz herramientas que funcionen muchos años.
  • Ligero en energía. Usa hardware viejo y servidores pequeños.
  • Reparable. Publica el código. Escribe instrucciones cortas.
  • Primero local. Guarda los datos en el grupo. No rastrees a las personas.
  • IA crítica. Usa IA solo cuando ayuda al grupo. A veces la mejor opción es no usar IA.

3. proyectos

Estos proyectos ya existen. Son las primeras partes de la plataforma.

Radiolibre

Una radio comunitaria en un servidor pequeño. Icecast envía el audio y un reproductor web estático lo recibe. Quien escucha no necesita una cuenta.

funciona en :: un VPS, Icecast, nginx :: radiolibre.altred.xyz :: código

iScream

Sal al aire desde el navegador de un teléfono. No necesitas una app ni una cuenta. El servidor no guarda audio ni registros de acceso. Un puente conecta el chat IRC y el grupo de Telegram.

funciona en :: Node, ffmpeg, Ergo IRC :: reporta.altred.xyz :: código aún no público

LiquidIce

Un bot de Telegram para un grupo. Los miembros envían fotos, textos, audio y video. El bot hace un archivo web y una transmisión de radio. Guarda una copia en archive.org.

funciona en :: Raspberry Pi 3B+, Liquidsoap :: código aún no público :: primera versión Telegram2Icecast

KLAP :: Klimat Action Protocol

Una herramienta libre para decisiones de grupo. Una persona escribe una afirmación. Otras personas agregan razones: porque, pero, sin embargo. La herramienta muestra dónde está de acuerdo el grupo.

funciona en :: Django, Docker, tu propio servidor :: klap.altred.xyz :: código :: basado en arguman.org

AudioMoth scripts

Scripts para grabaciones de campo de grabadoras AudioMoth. Encuentran eventos sonoros, calculan índices acústicos y hacen un calendario estacional. Todo el proceso es local, sin nube.

funciona en :: un portátil, Bash, Python, ffmpeg :: bioacustic-scripts :: audiomoth-scripts

SoundWalk :: DerivaSonora

Una app de teléfono para caminatas sonoras. Graba sonidos con su ubicación, agrega notas y escucha de nuevo en un mapa. Funciona sin conexión: sin cuenta, sin servidor, sin rastreo.

funciona en :: teléfonos Android, navegador :: biomapp.vercel.app :: código aún no público

4. mapa

Los proyectos se conectan en tres ramas: escuchar, decidir y transmitir.

5. siguiente

El siguiente paso es una red que no necesita internet ni grandes empresas.

  • Reticulum. Una pila de red para redes en malla. Funciona sobre radio LoRa, radio por paquetes, Wi-Fi e internet. Los grupos envían mensajes sin un servidor central.
  • Telegram. Muchos grupos usan Telegram hoy. Los bots siguen siendo la puerta de entrada simple. Después, un puente conecta Telegram y Reticulum.
  • IA local. Modelos pequeños funcionan en el hardware propio del grupo. Ejemplos: voz a texto para archivos de radio, resúmenes de debates en KLAP. Ningún dato va a una nube.
